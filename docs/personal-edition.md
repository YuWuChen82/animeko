# 个人版维护

个人仓库：<https://github.com/YuWuChen82/animeko>。上游：<https://github.com/open-ani/animeko>。

## 播放设置

设置中的播放器区域提供键盘快捷键列表，可选择字母、数字、方向键、空格和 F1–F12，也可取消绑定。
已有按键发生冲突时，确认交换两个操作的绑定。恢复默认按钮使用官方默认映射。
搜索框和弹幕输入期间保留播放器的输入保护；Ctrl、Alt、Meta 组合键交给系统和页面控件。

“记住音轨和字幕”按番剧保存用户的手动选择，换集、重新进入播放器和应用重启后恢复。
保存内容使用语言、名称和标签，匹配时使用当前视频的轨道对象，不依赖跨文件不稳定的轨道编号。
关闭字幕同样会被记住。新文件没有相应轨道时使用播放器默认选择，原有记忆仍保留。
设置中可以关闭记忆或清空历史；最多保留最近 128 个自定义番剧。

## 上游自动同步与 Windows 安装包

首次使用需要在 Fork 的 Actions 页面启用工作流。`Personal Windows build and upstream sync`
每天北京时间 04:17 检查官方 main，也支持手动运行；GitHub 定时任务可能延迟。
main 收到个人修改时同样触发测试和打包。

同步工作流在临时工作区合并官方 main，执行播放器、数据层及设置页测试，再构建 Windows x64 个人版。
这些检查全部成功后才推送合并提交。出现冲突、编译错误或测试失败时，远程 main 保持原样，
在 Actions 的失败日志中查看原因。并发提交由普通 Git 快进检查保护，工作流不强制推送。

个人版 ZIP 发布在 Fork 自己的 Releases，同时提供 14 天有效的 Actions 构建产物。
代码自动同步不会自动替换本机已安装程序。安装个人版后应关闭应用内的官方自动更新，
从个人仓库 Releases 更新，以保留这些功能。已有音轨、字幕偏好需在个人版中选择一次。

此工作流不需要个人访问令牌，使用仅对当前仓库有效的 `GITHUB_TOKEN`。
个人构建不包含官方私有服务密钥；需要第三方服务密钥的功能受上游构建文档所列限制。

本 Fork 仅构建 Windows x64。个人工作流会禁用继承的其他 GitHub Actions 工作流，保留官方源码，避免触发 Android、macOS 和 Linux 构建。
